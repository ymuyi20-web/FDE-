# 第一周详细学习计划

第一周目标：掌握足以继续开发AI应用的Python、Git、HTTP/JSON基础，完成“水稻成本计算器”和第一次模型API调用。

建议时间：每天5小时。每天固定结构为：学习1.5小时、跟做1小时、独立实操1.5小时、测试0.5小时、复盘0.5小时。

## 第1天：环境、变量与输入输出

### 学习目标

- 理解程序、解释器、文件、终端分别是什么；
- 会运行Python文件；
- 会使用变量、字符串、整数、小数、`print()`、`input()`；
- 知道报错信息应从最后一行开始看。

### 时间安排

| 时间 | 任务 |
|---|---|
| 09:00-10:00 | 安装/确认Python、VS Code和Git；创建项目文件夹和虚拟环境 |
| 10:10-11:00 | 视频：Python变量、数据类型、输入输出对应章节 |
| 14:00-15:00 | 跟写3个小程序：姓名介绍、亩数换算、产量计算 |
| 15:10-16:10 | 独立完成 `day1_farm_profile.py` |
| 16:10-16:40 | 分别输入正常值、0、负数、文字，记录现象 |
| 16:40-17:10 | 写复盘：今天能解释的5个概念和1个报错 |

### 独立任务

程序接收姓名、水稻面积、亩产，输出总产量和一段完整说明。禁止直接照抄答案；先写流程，再让Codex检查。

### 验收

- 能独立修改面积和亩产字段；
- 能说明为什么亩产应使用数字类型；
- 能解释`input()`返回什么类型；
- 产出：`day1_farm_profile.py`、`notes/day1.md`。

- 能遍历农资项目并累计成本。

### 时间安排

| 10:10-11:00 | 跟做：判断亩产是否达标；遍历3种农资 |

| 16:20-17:00 | 不看代码口述输入、计算和输出过程；提交Git |

### 独立任务

使用列表和字典保存种子、肥料、植保的亩成本，计算每亩成本和指定面积总成本。若面积小于等于0，应提示错误。

### 验收
