# Day8 学习复盘

## 学习时长

约 2 小时。

## 今天学了什么

- 学习了 JSON 配置文件的基础用法。
- 练习了创建、读取、写入和保存 JSON 文件。
- 使用 `farm_inputs.json` 保存农资成本配置。
- 使用 Python 读取 JSON 数据，并完成每亩成本和预计总成本计算。
- 使用 `day8_result.json` 保存计算结果。

## 今天的卡点

主要卡在文件名看错。

一开始把输入配置文件和输出结果文件混在一起了：

- `farm_inputs.json` 是输入配置文件。
- `day8_result.json` 是输出结果文件。

因为看错文件名，所以误以为程序会自动把配置改回去。

## 如何解决

重新区分两个文件的作用：

- 修改成本时，只改 `farm_inputs.json`。
- 运行正式作业后，程序会生成或更新 `day8_result.json`。

之后重新测试了灌溉成本从 80 改成 100，结果正确变为每亩总成本 475 元。

## 今天最大的收获

今天最大的收获是理解了 JSON 配置文件的作用。

以前成本数据是写在 Python 代码里的，现在可以把数据放到 JSON 文件里，让 Python 专门负责读取、计算和保存结果。

`JSON`、`json.load()`、`json.dump()`、配置文件、输入文件、输出文件。
