# Day 02 提交计划

## 提交 1：Day 1 业务边界

### 目的

补充价格数据时效性和模拟数据使用边界。

### 应包含

- `day-01/PROJECT_CONTRACT.md`
- `day-01/ISSUE_DRAFT.md`

### 不应包含

- Day 2 学习材料；
- Python 缓存；
- `.env` 或密钥；
- 与本次目的无关的 README 换行变化。

### 提交标题

```text
docs: 补充价格来源与模拟数据边界
```

## 提交 2：Day 2 仓库审计

### 目的

加入仓库审计工具和当天操作说明。

### 应包含

- `day-02/DAY02-学习计划.md`
- `day-02/COMMIT_PLAN.md`
- `day-02/day02_repo_audit.py`

### 不应包含

- Day 1 文档；
- 其他历史练习；
- 自动生成的报告、缓存或环境文件。

### 提交标题

```text
chore: 添加 Day 2 仓库审计材料
```

## 提交前检查

- [ ] 我能用一句话说明这次提交为什么存在；
- [ ] 我查看了每个文件的 diff；
- [ ] 没有密钥、密码或真实敏感业务数据；
- [ ] 没有无关文件；
- [ ] 提交标题不是 `update`、`修改`或`学习`。
