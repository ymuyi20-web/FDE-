# Issue：整理水稻农资成本计算器 v1.0

## 背景

现有 Python 练习已经能够读取 JSON、计算农资成本并输出结果，但代码和说明分散，其他人难以判断输入要求、适用范围和完成标准。

## 用户

需要快速核算水稻农资投入的农业生产管理人员。

## 本次任务

- 整理一个可以独立运行的成本计算器；
- 从 JSON 样例读取农资名称和亩成本；
- 由用户输入种植面积；
- 输出每亩总成本和预计总成本；
- 对无效面积和错误配置给出明确提示；
- 写清人工确认点与业务边界。

## 明确不做

- 不接入作物模型；
- 不输出肥料推荐或施肥处方；
- 不引入 AI API；
- 不使用真实敏感数据；
- 不开发网页界面。

## 验收标准

- [ ] 输入 `100` 亩时可以正常计算；
- [ ] 面积为 0、负数或非数字时不继续计算；
- [ ] 农资成本为负数、非数字或缺字段时给出错误信息；
- [ ] 输出同时显示元/亩和元；
- [ ] 项目契约写清输入、输出、限制和人工确认点；
- [ ] 新用户能根据说明理解该工具不构成施肥建议。
