# 水稻当季氮磷钾投入量核算器：设计草稿

## 1. 项目定位

这个小程序用于核算一季水稻在不同施肥阶段投入的氮、磷、钾养分量。

它只根据用户输入的肥料养分含量和亩用量进行确定性计算，不判断用量是否合理，也不生成施肥处方。

## 2. 关键边界

当前按中国常见肥料标签口径计算：

- 氮：`N`
- 磷：`P2O5`
- 钾：`K2O`

也就是说，常见的“三个 15 复合肥”在这里表示：

```text
N = 15%
P2O5 = 15%
K2O = 15%
```

不是元素态 P 和元素态 K。

## 3. 用户输入

用户按施肥阶段输入：

- 底肥；
- 分蘖肥；
- 穗肥。

每个阶段可以有一种或多种肥料。

每种肥料需要输入：

```text
fertilizer_name      肥料名称
amount_kg_per_mu     亩用量，单位 kg/亩
n_percent            N 含量，百分比
p2o5_percent         P2O5 含量，百分比
k2o_percent          K2O 含量，百分比
source               数据来源
is_mock              是否为模拟数据
```

## 4. 输出

程序输出：

- 每个阶段用了什么肥；
- 每个阶段的 N、P2O5、K2O 投入量，单位 kg/亩；
- 全季总 N、P2O5、K2O 投入量，单位 kg/亩。

## 5. 计算公式

单个肥料：

```text
N投入量 = 亩用量 × N含量 / 100
P2O5投入量 = 亩用量 × P2O5含量 / 100
K2O投入量 = 亩用量 × K2O含量 / 100
```

阶段合计：

```text
阶段合计 = 该阶段所有肥料养分投入量相加
```

全季合计：

```text
全季合计 = 底肥 + 分蘖肥 + 穗肥
```

## 6. 样例场景

- 底肥：三个 15 复合肥，35 kg/亩；
- 分蘖肥：尿素，20 kg/亩，N=46%；
- 穗肥：三个 15 复合肥 10 kg/亩 + 氯化钾 10 kg/亩，K2O=60%。

全季结果应为：

```text
N    = 15.95 kg/亩
P2O5 = 6.75 kg/亩
K2O  = 12.75 kg/亩
```

## 7. 明确不做

- 不判断施肥量是否科学；
- 不推荐肥料产品；
- 不接入作物模型；
- 不接入土壤、气象或田间验证数据；
- 不替代农艺师和业务人员审核；
- 不构成施肥处方或采购依据。

## 8. 和智慧农业研究员岗位的关系

这个工具可以作为“肥料决策层”里的一个很小的确定性计算模块。

真实岗位中，它前面需要可靠输入：

- 作物模型输出；
- 土壤养分数据；
- 区域种植习惯；
- 肥料产品库；
- 田间验证结果。

它后面还需要专家审核、区域化校正和试验反馈。
