# 水稻当季氮磷钾投入量核算器：设计草稿

## 1. 项目定位

这个小工具用于核算一季水稻在不同施肥阶段投入的氮、磷、钾养分量。

它只根据用户输入的肥料养分含量和亩用量进行确定性计算，不判断用量是否合理，也不生成施肥处方。

当前交付形态包括：

- `index.html`：面向普通用户的单页网页工具，可直接通过浏览器打开；
- `src/season_npk.py`：用于学习和验证的 Python 计算核心；
- `data/sample_plan.json`：样例施肥方案；
- `tests/test_season_npk.py`：自动化测试。

## 2. 关键边界

当前按中国常见肥料标签口径计算：

- 氮：`N`
- 磷：`P2O5`
- 钾：`K2O`

也就是说，常见的“三个 15 复合肥”在这里表示：

```text
N = 15%
P2O5 = 15%
K2O = 15%
```

不是元素态 P 和元素态 K。

## 3. 用户输入

用户按施肥阶段输入：

- 底肥；
- 分蘖肥；
- 穗肥。

每个阶段可以有一种或多种肥料。

每种肥料需要输入：

```text
fertilizer_name      肥料名称
amount_kg_per_mu     亩用量，单位 kg/亩
n_percent            N 含量，百分比
p2o5_percent         P2O5 含量，百分比
k2o_percent          K2O 含量，百分比
source               数据来源
is_mock              是否为模拟数据
```

在网页产品中，普通用户看到的是中文字段：

```text
肥料名称
亩用量，单位 kg/亩
N 含量，单位 %
P2O5 含量，单位 %
K2O 含量，单位 %
```

用户只需要填写数值，单位固定展示在输入框旁边。

网页产品允许用户在每个阶段动态添加或删除肥料。

另外，网页底部提供一个可选输入项：

```text
目标产量，单位 kg/亩
```

该字段不参与 N、P2O5、K2O 投入量核算，只用于粗略估算目标产量对应的适宜施氮量范围。

## 4. 输出

程序输出：

- 每个阶段用了什么肥；
- 每个阶段的 N、P2O5、K2O 投入量，单位 kg/亩；
- 全季总 N、P2O5、K2O 投入量，单位 kg/亩。

如果用户填写目标产量，网页还会额外输出一段文字说明：

- 目标产量对应的作物需氮量；
- 假设土壤可提供 50% 氮素后的肥料补充需求；
- 按肥料利用率 35% 折算后的施氮量；
- 以该值上下浮动 10% 得到的估算范围；
- 当前方案核算出的 N 投入量是否落在该范围内。

## 5. 计算公式

单个肥料：

```text
N投入量 = 亩用量 × N含量 / 100
P2O5投入量 = 亩用量 × P2O5含量 / 100
K2O投入量 = 亩用量 × K2O含量 / 100
```

阶段合计：

```text
阶段合计 = 该阶段所有肥料养分投入量相加
```

全季合计：

```text
全季合计 = 底肥 + 分蘖肥 + 穗肥
```

目标产量施氮量估算：

```text
作物需氮量 = 目标产量 / 100 × 2
土壤供氮量 = 作物需氮量 × 50%
需由肥料补充的氮量 = 作物需氮量 - 土壤供氮量
折算施氮量 = 需由肥料补充的氮量 / 35%
估算范围下限 = 折算施氮量 × 90%
估算范围上限 = 折算施氮量 × 110%
```

例如目标产量为 600 kg/亩：

```text
作物需氮量 = 600 / 100 × 2 = 12.00 kg/亩
土壤供氮量 = 12.00 × 50% = 6.00 kg/亩
需由肥料补充的氮量 = 12.00 - 6.00 = 6.00 kg/亩
折算施氮量 = 6.00 / 35% = 17.14 kg N/亩
估算范围 = 15.43 至 18.86 kg N/亩
```

## 6. 样例场景

- 底肥：三个 15 复合肥，35 kg/亩；
- 分蘖肥：尿素，20 kg/亩，N=46%；
- 穗肥：三个 15 复合肥 10 kg/亩 + 氯化钾 10 kg/亩，K2O=60%。

全季结果应为：

```text
N    = 15.95 kg/亩
P2O5 = 6.75 kg/亩
K2O  = 12.75 kg/亩
```

## 7. 明确不做

- 不判断施肥量是否科学；
- 不推荐肥料产品；
- 不接入作物模型；
- 不接入土壤、气象或田间验证数据；
- 不替代农艺师和业务人员审核；
- 不构成施肥处方或采购依据；
- 不把目标产量估算结果视为正式推荐施氮量；
- 不根据品种、土壤肥力、前茬、气象、水分管理或田间长势自动调整参数。

## 8. 网页交付说明

网页产品入口文件为：

```text
index.html
```

本地使用方式：

```text
双击 index.html，用浏览器打开。
```

GitHub Pages 发布后，用户可以通过网页链接访问。

当前网页产品的核心交付标准是：

- 用户不需要安装 Python；
- 用户不需要懂命令行；
- 用户可以直接填写底肥、分蘖肥、穗肥数据；
- 输入框旁边明确展示单位；
- 点击一次按钮即可得到阶段合计、全季合计和可选施氮量估算；
- 页面明确提示结果边界。

## 9. 和智慧农业研究员岗位的关系

这个工具可以作为“肥料决策层”里的一个很小的确定性计算模块。

真实岗位中，它前面需要可靠输入：

- 作物模型输出；
- 土壤养分数据；
- 区域种植习惯；
- 肥料产品库；
- 田间验证结果。

它后面还需要专家审核、区域化校正和试验反馈。
