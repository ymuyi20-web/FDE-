# 水稻农资成本核算器 v1.0

## 解决的问题

这个工具用于快速核算水稻种植中的农资投入成本。

它适合农业生产管理人员在整理预算、复核方案或准备沟通材料时，基于一组已确认的农资单价，计算：

- 每亩农资总成本；
- 指定种植面积下的预计总成本。

## 适用用户

- 农业生产管理人员；
- 区域种植项目负责人；
- 需要核算农资预算的业务人员；
- 正在学习 FDE 交付流程的农业垂直方向学习者。

## 当前版本能做什么

- 从 JSON 文件读取农资名称和亩成本；
- 校验种植面积必须大于 0；
- 校验农资成本必须是数字且不能小于 0；
- 校验价格来源、有效日期和是否为模拟数据；
- 输出每亩总成本和预计总成本；
- 用自动化测试保护 10 条基础承诺。

## 明确不做什么

本工具只做成本核算，不做以下事情：

- 不接入第三方作物模型；
- 不生成施肥处方；
- 不判断肥料产品是否适合某块田；
- 不替代农艺师、业务人员或采购人员的人工确认；
- 不构成真实采购依据；
- 不使用真实敏感业务数据。

## 输入数据

样例数据文件：

```text
exercises/fde-16week/week-01/day-03/data/farm_inputs.example.json
```

每条农资数据必须包含：

```text
name            农资名称
cost_per_mu     亩成本，单位为元/亩
unit            单位，当前必须为元/亩
source          价格来源
effective_date  价格有效日期
is_mock         是否为模拟数据
```

样例：

```json
{
  "name": "肥料",
  "cost_per_mu": 200.0,
  "unit": "元/亩",
  "source": "模拟数据",
  "effective_date": "2026-07-26",
  "is_mock": true
}
```

在项目根目录运行：


## 已知限制

- 当前仅核算成本，不判断农资产品是否适合具体作物、土壤或田块；
- 当前不接入气象、土壤、作物模型或田间验证数据；
- 当前样例价格为模拟数据，不能作为真实采购依据；
- 价格来源和有效日期必须由业务人员人工确认；
- 若用于真实项目，必须先替换为经过确认的区域价格和产品数据。
- 欢迎测试使用

## 智慧农业岗位相关边界

如果未来扩展到“第三方作物模型之外的肥料决策层”，本工具只能作为成本核算环节的一部分。

进入真实肥料决策前，还必须补充并人工确认：

- 作物模型输出；
- 土壤养分数据；
- 气象和区域种植习惯；
- 肥料产品库；
- 田间验证结果；
- 区域化参数和专家审核意见。

## 安全提醒

本项目仅用于学习和成本核算演示，不构成施肥处方、采购依据或农艺建议。
