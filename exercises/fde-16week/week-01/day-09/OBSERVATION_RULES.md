# Day 09 观察待办规则说明

## 1. 这个模块解决什么问题

Day 8 的看板回答：

> 各材料、各播期现在到什么生育期了？

Day 9 的待办模块回答：

> 今天哪些材料、哪些播期、哪些小区应该优先去看？

对于育种基地来说，这很重要。  
因为材料多、播期多、生育期错开后，靠脑子记很容易漏看。

## 2. 默认观察规则

第一版先采用一套简单规则：

| 当前生育期 | 建议复查间隔 |
| --- | ---: |
| 播种 | 7 天 |
| 出苗 | 10 天 |
| 分蘖 | 14 天 |
| 拔节 | 7 天 |
| 孕穗 | 5 天 |
| 抽穗 | 3 天 |
| 灌浆 | 7 天 |
| 成熟 | 5 天 |
| 收获 | 999 天 |

解释：

- 播种后要尽快看出苗；
- 分蘖期变化相对慢，可以间隔稍长；
- 孕穗、抽穗阶段变化快，需要更高频观察；
- 收获后通常不再生成紧急复查任务。

## 3. 任务状态

脚本会根据“最近观察日期 + 建议复查间隔”生成下一次应观察日期。

然后与今天日期比较：

| 状态 | 含义 |
| --- | --- |
| 逾期 | 应观察日期早于今天 |
| 今日到期 | 应观察日期等于今天 |
| 即将到期 | 距离应观察日期 1-3 天 |
| 正常跟踪 | 距离应观察日期超过 3 天 |

## 4. 边界

这个模块只生成观察提醒，不做育种评价。

它可以说：

> 稻香A 第一播期已经到抽穗期，距离上次记录已超过 3 天，建议复查。

但不能说：

> 稻香A 表现优秀，建议保留。

后者属于育种专家判断。

## 5. 后续可迭代方向

如果朋友试用后觉得方向对，可以继续加：

- 负责人；
- 手机提醒；
- 拍照记录；
- 逾期原因；
- 是否已完成；
- 按基地/地块筛选；
- 自动根据播种日期预测生育期；
- 预测结果允许人工修改。
