# Day 07 预期输出示例

运行脚本后，会生成：

```text
breeding_summary.generated.md
```

报告大致包含：

## 1. 数据总览

- 记录数：5
- 品种数：2
- 播期数：2
- 小区数：3
- 日期范围：2026-05-01 至 2026-07-18

## 2. 按品种汇总

示例：

```text
稻香A
- 记录数：3
- 涉及播期：第一播期、第二播期
- 涉及小区：A-01、A-02
- 最近记录：2026-07-18，抽穗，A-01
```

## 3. 按品种 + 播期汇总

示例：

```text
稻香A / 第一播期
- 小区：A-01
- 记录数：2
- 生育期进展：播种 → 抽穗
- 最近记录：2026-07-18，抽穗
```

## 4. 边界提醒

报告会明确说明：

```text
本报告只整理已有记录，不判断品种表现，不生成农事建议。
```
