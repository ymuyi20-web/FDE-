# FDE农业AI实战学习项目

这是杨其琛的6周FDE转型实验项目。目标不是6周后宣称成为成熟FDE，而是完成一个可演示、可测试、可部署的农业AI应用，并具备申请农业AI实施、解决方案助理、行业交付或初级AI应用工程岗位的作品证据。

## 立即开始

1. 双击 `打开学习控制台.bat`，浏览器会通过 `http://127.0.0.1:8765/` 打开学习控制台。
   - 第一次打开时会自动启动本地预览服务，无需安装其他软件。
   - 如果服务已经运行，会直接复用，不会重复启动。
   - `index.html` 是网页源文件，在 Codex 文件查看器中点击会显示代码，这是正常现象。
2. 阅读 `docs/01-六周总路线.md`。
3. 按 `docs/02-第一周详细计划.md` 从第1天开始。
4. 每天把练习代码保存在 `exercises/week-01/`，不要只观看课程。
5. 每天在学习控制台填写完成情况、学习时长、报错和复盘。

## 6周最终作品

水稻生产与成本管理助手：

- 上传经过脱敏的农业资料；
- 基于资料回答问题并展示引用；
- 输入面积、品种、播期和目标产量，生成农事计划；
- 调用确定性程序计算农资成本及预计利润；
- 保存操作日志和用户反馈；
- 用至少30条测试问题评估可靠性；
- 部署为可供真实用户试用的网页。

## 学习纪律

- 每天约5小时，其中视频和阅读最多2小时，实操至少2.5小时。
- 可以让Codex解释、生成示例和协助排错，但必须能说明代码的数据流和修改位置。
- 连续卡住30分钟时，整理“目标、现象、报错、已尝试方法”后再向Codex求助。
- 每天必须留下可检查的文件、运行结果或测试记录。
- 暂不学习模型训练、微调、复杂算法、React、Kubernetes和多智能体框架。
